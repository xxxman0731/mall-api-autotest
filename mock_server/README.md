# 电商 Demo 被测系统

基于 Flask + SQLite 的简易电商后端,专为接口自动化测试练习设计。

## 启动

```bash
python mock_server/app.py
```

服务地址: http://127.0.0.1:5000

浏览器打开 http://127.0.0.1:5000 可直接访问商城前端页面(商品浏览 / 登录注册 / 下单 / 我的订单)。

## 接口清单

| 方法 | 路径 | 说明 | 认证 |
| --- | --- | --- | --- |
| GET | / | 商城前端页面 | 否 |
| GET | /api/health | 健康检查 | 否 |
| POST | /api/register | 注册 | 否 |
| POST | /api/login | 登录(返回 token) | 否 |
| GET | /api/products | 商品列表 | 否 |
| GET | /api/products/:id | 商品详情 | 否 |
| POST | /api/orders | 创建订单 | 是 |
| GET | /api/orders | 我的订单列表 | 是 |
| GET | /api/orders/:order_no | 订单详情 | 是 |

认证方式:请求头 `Authorization: Bearer <token>`

## 业务规则

- 用户名:3-20 位字母、数字、下划线,不可重复
- 密码:至少 6 位,数据库中存储加盐 MD5(仅教学演示)
- 手机号:可选,需为 11 位数字
- 下单数量:1-99 的整数,不能超过库存
- 订单只能由下单人查看

## 业务错误码

| code | HTTP | 含义 |
| --- | --- | --- |
| 0 | 200/201 | 成功 |
| 400 | 400 | 缺少必填参数 |
| 1001 | 400 | 用户名格式非法 |
| 1002 | 400 | 密码长度不足 |
| 1003 | 400 | 手机号格式非法 |
| 1004 | 409 | 用户名已存在 |
| 1005 | 401 | 用户名或密码错误 |
| 1006 | 404 | 商品不存在 |
| 1007 | 401 | 未登录或 token 无效 |
| 1008 | 400 | 下单参数非法 |
| 1009 | 400 | 库存不足 |
| 1010 | 404 | 订单不存在 |
| 1011 | 403 | 无权访问该订单 |
